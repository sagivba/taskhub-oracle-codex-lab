# Evidence

Store concise milestone evidence here when it is useful for review or resumption.

Good evidence:

- PASS/FAIL summary;
- expected vs actual object/grant manifest;
- concise compile-error output;
- ordered list of applied change files;
- rebuild completion note.

Do not store:

- passwords;
- wallets;
- saved connection stores;
- large raw dumps that are not needed for review.

Environment-specific evidence that should not be committed can be placed under `evidence/local/`, which is ignored by Git.
